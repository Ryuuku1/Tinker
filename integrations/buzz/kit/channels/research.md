# #research: answers with sources from Tinker Researcher

Ask one focused question here. This is Tinker Researcher's own channel, so no @mention is needed (elsewhere,
@mention **@Tinker Researcher**). It reads the repositories under `/repos` and current primary sources on the
web, and changes nothing.

## Try

- `What does Claude Code's dontAsk permission mode do today? Official docs only.`
- `Which relay settings in /repos/<name>/integrations/buzz decide who may connect? Cite file:line.`
- `Docker Desktop on Windows: bind mount or volume for a read-only repository? Sources.`

## You get

A short conclusion first, then facts with a source each (a URL or `file:line`), then inferences and
open questions; `not-verified` where it found no source. For what the answer means for the code, use
`research <question>` in #flows.

## Careful

Web pages can carry instructions aimed at agents. Every agent treats them as data, but ask about pages
you would open yourself, and never put a secret in a question.

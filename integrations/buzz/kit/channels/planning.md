# #planning: shape it before anyone builds it, with Tinker Planner

Write an idea, a problem or a feature request here. This is Tinker Planner's own channel, so no @mention is
needed (elsewhere, @mention **@Tinker Planner**). It reads the repositories under `/repos` and the web to ground
the plan, and changes nothing: `/repos` and `/work` are read-only for it, and its edit tools are denied.

## Try

- `Shape: a command that copies an agent's work folder to my PC. Outcome, scope, acceptance criteria.`
- `Setup asks four questions. Which could it answer itself? Options, trade-offs, a recommendation.`
- `Turn this bug report into acceptance criteria a test could check: <paste the report>.`

## You get

A short brief: the problem and the outcome, in and out of scope, acceptance criteria, the user flow and
its states, risks and open questions. Hand it to Tinker in #requests to build and to Tinker Tester in
#testing to turn the criteria into tests, no @mention needed in either, or run it all with `story <request>`
in #flows.

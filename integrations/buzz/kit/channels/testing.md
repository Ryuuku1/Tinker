# #testing: tests written and run by Tinker Tester

Write what to verify here. This is Tinker Tester's own channel, so no @mention is needed (elsewhere, @mention
**@Tinker Tester**). It works only in its own folder under `/work` (`/work/test-<topic>`): a fresh clone of a
repository under `/repos`, or a copy of another agent's folder. It never changes the code under test unless you
ask; it reports defects with a failing test as evidence.

## Try

- `Clone /repos/<name> into /work/test-suite and run the full suite. Counts and any failures.`
- `Copy /work/<topic> (Tinker's change) and write tests for its acceptance criteria: <criteria>.`
- `Which behaviors in integrations/buzz/kit/kit.ps1 have no test? Add the two riskiest.`

## You get

The folder, the exact commands, the counts (run, passed, failed, skipped), each failure with its first
relevant lines, and the gaps it did not cover. Copy its folder to your PC with `Copy-AgentWork`
(GUIDE.md, section 10), or ask Tinker Reviewer in #reviews to review it.
